Questions

Is Add To Do free?

Yes. There is no sign-up and no ads.

Where are my tasks stored?

Only on your device. There is no cloud backup yet, so clearing the app's data or uninstalling it removes your tasks.

Why does Android warn me when I install?

The APK comes from this site, not the Play Store, so Android asks you to confirm. You only need to allow it once.

Can I use it on an iPhone?

The APK is for Android only. On an iPhone you can try Add To Do in the browser with Open web app. It is a test drive, so your tasks stay in that browser.
